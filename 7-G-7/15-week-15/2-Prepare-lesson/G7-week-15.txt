Lesson Plan (خطة الدرس)
Lesson Title (عنوان الدرس):
Code for 2D Graphics (كتابة الشفرة للرسومات ثنائية الأبعاد)

Class (الفصل):
First Intermediate Grade (الصف الأول المتوسط)

Day (اليوم):
Tuesday (الثلاثاء)

Lesson Objectives (أهداف الدرس):
By the end of this lesson, students will be able to:
1. Understand the basics of 2D graphics programming.
2. Write code to create simple 2D graphics.

Period (الفترة الزمنية):
45 minutes (45 دقيقة)

Date (التاريخ):
[Insert Date] (تاريخ اليوم)

Strategy (الاستراتيجية):
Hands-on Activity, Discussion (نشاط عملي، مناقشة)

New Vocabularies (المفردات الجديدة):
1. 2D Graphics (الرسومات ثنائية الأبعاد)
2. Programming Language (لغة البرمجة)
3. Shape (الشكل)
4. Color (اللون)

Teaching Aids (الوسائل التعليمية):
1. Computer with programming software (جهاز كمبيوتر مع برنامج برمجة)
2. Whiteboard (السبورة)
3. Markers (علامات)
4. Examples of 2D graphics code (أمثلة على شفرة الرسومات ثنائية الأبعاد)

Time (الوقت):
- Warm-up: 5 minutes (التهيئة: 5 دقائق)
- Procedures: 30 minutes (الإجراءات: 30 دقيقة)
- Evaluation: 5 minutes (التقييم: 5 دقائق)
- Homework: 5 minutes (الواجب المنزلي: 5 دقائق)

Warm-up (التهيئة):
- Greet the students and ask if they know what 2D graphics programming is.
- تحية الطلاب وسؤالهم إذا كانوا يعرفون ما هي برمجة الرسومات ثنائية الأبعاد.

Procedures (الإجراءات):
1. Introduction (5 minutes):
    - Introduce the basics of 2D graphics programming.
    - Explain how to use a programming language to create 2D graphics.
    - تقديم أساسيات برمجة الرسومات ثنائية الأبعاد.
    - شرح كيفية استخدام لغة برمجة لإنشاء رسومات ثنائية الأبعاد.
2. Hands-on Activity (15 minutes):
    - Let students work in pairs to write code for simple 2D graphics.
    - Ask students to experiment with different shapes and colors.
    - دع الطلاب يعملون في أزواج لكتابة شفرة رسومات ثنائية الأبعاد بسيطة.
    - اطلب من الطلاب تجربة أشكال وألوان مختلفة.
3. Discussion (10 minutes):
    - Discuss the challenges and solutions in 2D graphics programming.
    - Ask students to share their experiences and what they learned.
    - مناقشة التحديات والحلول في برمجة الرسومات ثنائية الأبعاد.
    - اطلب من الطلاب مشاركة تجاربهم وما تعلموه.

Evaluation (التقييم):
- Observe students' participation in the hands-on activity.
- Ask students questions about 2D graphics programming and code.
- مراقبة مشاركة الطلاب في النشاط العملي.
- سؤال الطلاب عن برمجة الرسومات ثنائية الأبعاد والشفرة.

Homework (الواجب المنزلي):
- Write code for a simple 2D graphic using a programming language.
- كتابة شفرة رسم ثنائي الأبعاد بسيط باستخدام لغة برمجة.
