Lesson Plan (خطة الدرس)
Lesson Title (عنوان الدرس):
Web Layout Design (تصميم تخطيط الويب)

Class (الفصل):
First Intermediate Grade (الصف الأول المتوسط)

Day (اليوم):
Sunday (الأحد)

Lesson Objectives (أهداف الدرس):
By the end of this lesson, students will be able to:
1. Understand the principles of web layout design.
2. Design a basic web layout using HTML and CSS.

Period (الفترة الزمنية):
45 minutes (45 دقيقة)

Date (التاريخ):
[Insert Date] (تاريخ اليوم)

Strategy (الاستراتيجية):
Discussion, Hands-on Activity (مناقشة، نشاط عملي)

New Vocabularies (المفردات الجديدة):
1. Web Layout (تخطيط الويب)
2. Design Principles (مبادئ التصميم)
3. HTML Structure (هيكل HTML)
4. CSS Styling (تنسيق CSS)

Teaching Aids (الوسائل التعليمية):
1. Computer with text editor (جهاز كمبيوتر مع محرر نصوص)
2. Whiteboard (السبورة)
3. Markers (علامات)
4. Examples of web layouts (أمثلة على تخطيطات الويب)

Time (الوقت):
- Warm-up: 5 minutes (التهيئة: 5 دقائق)
- Procedures: 30 minutes (الإجراءات: 30 دقيقة)
- Evaluation: 5 minutes (التقييم: 5 دقائق)
- Homework: 5 minutes (الواجب المنزلي: 5 دقائق)

Warm-up (التهيئة):
- Greet the students and ask if they know what web layout design is.
- تحية الطلاب وسؤالهم إذا كانوا يعرفون ما هو تصميم تخطيط الويب.

Procedures (الإجراءات):
1. Introduction (5 minutes):
    - Introduce the principles of web layout design.
    - Explain the importance of HTML structure and CSS styling.
    - تقديم مبادئ تصميم تخطيط الويب.
    - شرح أهمية هيكل HTML وتنسيق CSS.
2. Hands-on Activity (15 minutes):
    - Let students work in pairs to design a basic web layout using HTML and CSS.
    - Ask students to apply design principles to their layout.
    - دع الطلاب يعملون في أزواج لتصميم تخطيط ويب بسيط باستخدام HTML وCSS.
    - اطلب من الطلاب تطبيق مبادئ التصميم على تخطيطهم.
3. Discussion (10 minutes):
    - Discuss the importance of web layout design and its applications.
    - Ask students to share their experiences and what they learned.
    - مناقشة أهمية تصميم تخطيط الويب وتطبيقاته.
    - اطلب من الطلاب مشاركة تجاربهم وما تعلموه.

Evaluation (التقييم):
- Observe students' participation in the hands-on activity.
- Ask students questions about web layout design and its principles.
- مراقبة مشاركة الطلاب في النشاط العملي.
- سؤال الطلاب عن تصميم تخطيط الويب ومبادئه.

Homework (الواجب المنزلي):
- Design a basic web layout using HTML and CSS and apply design principles.
- تصميم تخطيط ويب بسيط باستخدام HTML وCSS وتطبيق مبادئ التصميم.
