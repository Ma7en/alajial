Lesson Plan (خطة الدرس)
Lesson Title (عنوان الدرس):
Draw Tool (أداة الرسم)

Class (الفصل):
First Intermediate Grade (الصف الأول المتوسط)

Day (اليوم):
Wednesday (الأربعاء)

Lesson Objectives (أهداف الدرس):
By the end of this lesson, students will be able to:
1. Understand the basic features of a draw tool.
2. Use a draw tool to create simple drawings.

Period (الفترة الزمنية):
45 minutes (45 دقيقة)

Date (التاريخ):
[Insert Date] (تاريخ اليوم)

Strategy (الاستراتيجية):
Hands-on Activity, Demonstration (نشاط عملي، عرض توضيحي)

New Vocabularies (المفردات الجديدة):
1. Draw Tool (أداة الرسم)
2. Shape (الشكل)
3. Line (الخط)
4. Color (اللون)

Teaching Aids (الوسائل التعليمية):
1. Computer with draw software (جهاز كمبيوتر مع برنامج رسم)
2. Whiteboard (السبورة)
3. Markers (علامات)
4. Examples of drawings created with a draw tool (أمثلة على رسومات تم إنشاؤها باستخدام أداة الرسم)

Time (الوقت):
- Warm-up: 5 minutes (التهيئة: 5 دقائق)
- Procedures: 30 minutes (الإجراءات: 30 دقيقة)
- Evaluation: 5 minutes (التقييم: 5 دقائق)
- Homework: 5 minutes (الواجب المنزلي: 5 دقائق)

Warm-up (التهيئة):
- Greet the students and ask if they know what a draw tool is.
- تحية الطلاب وسؤالهم إذا كانوا يعرفون ما هي أداة الرسم.

Procedures (الإجراءات):
1. Introduction (5 minutes):
    - Introduce the basic features of a draw tool.
    - Explain how to use a draw tool to create simple drawings.
    - تقديم الميزات الأساسية لأداة الرسم.
    - شرح كيفية استخدام أداة الرسم لإنشاء رسومات بسيطة.
2. Demonstration (10 minutes):
    - Demonstrate how to use a draw tool to create a simple drawing.
    - Show students how to use different shapes, lines, and colors.
    - عرض توضيحي لكيفية استخدام أداة الرسم لإنشاء رسم بسيط.
    - إظهار الطلاب كيفية استخدام أشكال وخطوط وألوان مختلفة.
3. Hands-on Activity (15 minutes):
    - Let students work in pairs to create a simple drawing using a draw tool.
    - Ask students to experiment with different features and tools.
    - دع الطلاب يعملون في أزواج لإنشاء رسم بسيط باستخدام أداة الرسم.
    - اطلب من الطلاب تجربة ميزات وأدوات مختلفة.

Evaluation (التقييم):
- Observe students' participation in the hands-on activity.
- Ask students questions about the draw tool and its features.
- مراقبة مشاركة الطلاب في النشاط العملي.
- سؤال الطلاب عن أداة الرسم وميزاتها.

Homework (الواجب المنزلي):
- Create a simple drawing using a draw tool and experiment with different features.
- إنشاء رسم بسيط باستخدام أداة الرسم وتجربة ميزات مختلفة.
