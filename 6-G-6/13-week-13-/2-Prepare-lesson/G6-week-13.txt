Lesson Plan (خطة الدرس)
Lesson Title (عنوان الدرس):
HTML (لغة ترميز النصوص التشعبية)

Class (الفصل):
Sixth Grade (الصف السادس الابتدائي)

Day (اليوم):
Tuesday (الثلاثاء)

Lesson Objectives (أهداف الدرس):
By the end of this lesson, students will be able to:
1. Understand the basic concepts of HTML.
2. Create a simple web page using HTML.

Period (الفترة الزمنية):
45 minutes (45 دقيقة)

Date (التاريخ):
[Insert Date] (تاريخ اليوم)

Strategy (الاستراتيجية):
Discussion, Hands-on Activity (مناقشة، نشاط عملي)

New Vocabularies (المفردات الجديدة):
1. HTML (لغة ترميز النصوص التشعبية)
2. Tag (العلامة)
3. Element (العنصر)
4. Attribute (السمة)

Teaching Aids (الوسائل التعليمية):
1. Computer with text editor (جهاز كمبيوتر مع محرر نصوص)
2. Whiteboard (السبورة)
3. Markers (علامات)
4. Examples of HTML code (أمثلة على شفرة HTML)

Time (الوقت):
- Warm-up: 5 minutes (التهيئة: 5 دقائق)
- Procedures: 30 minutes (الإجراءات: 30 دقيقة)
- Evaluation: 5 minutes (التقييم: 5 دقائق)
- Homework: 5 minutes (الواجب المنزلي: 5 دقائق)

Warm-up (التهيئة):
- Greet the students and ask if they know what HTML is.
- تحية الطلاب وسؤالهم إذا كانوا يعرفون ما هو HTML.

Procedures (الإجراءات):
1. Introduction (5 minutes):
    - Introduce the concept of HTML and its importance.
    - Explain the basic structure of an HTML document.
    - تقديم مفهوم HTML وأهميته.
    - شرح الهيكل الأساسي لوثيقة HTML.
2. Hands-on Activity (15 minutes):
    - Let students work in pairs to create a simple web page using HTML.
    - Ask students to use HTML tags to add headings, paragraphs, and images.
    - دع الطلاب يعملون في أزواج لإنشاء صفحة ويب بسيطة باستخدام HTML.
    - اطلب من الطلاب استخدام علامات HTML لإضافة عناوين، فقرات، وصور.
3. Discussion (10 minutes):
    - Discuss the importance of HTML in web development.
    - Ask students to share their experiences and what they learned.
    - مناقشة أهمية HTML في تطوير الويب.
    - اطلب من الطلاب مشاركة تجاربهم وما تعلموه.

Evaluation (التقييم):
- Observe students' participation in the hands-on activity.
- Ask students questions about HTML and its tags.
- مراقبة مشاركة الطلاب في النشاط العملي.
- سؤال الطلاب عن HTML وعلاماته.

Homework (الواجب المنزلي):
- Create a simple web page using HTML and add a heading, paragraph, and image.
- إنشاء صفحة ويب بسيطة باستخدام HTML وإضافة عنوان، فقرة، وصورة.
